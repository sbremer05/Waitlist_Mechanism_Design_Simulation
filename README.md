# Agent-Based Monte Carlo Simulation of Allocation Mechanisms

A stochastic, agent-based Monte Carlo simulation for comparing **FCFS, priority-based, and commitment allocation mechanisms** under strategic behavior, uncertain participation, and agent dropout.

The project models competitive allocation markets across varying supply-demand regimes and evaluates mechanisms using **efficiency, fairness, and resource utilization** over **150,000+ simulation trials**.

## Overview

Allocation mechanisms often perform differently when agents have heterogeneous valuations, make strategic participation decisions, and may drop out before receiving an allocation.

This simulation studies how increasing strategic behavior affects three allocation mechanisms:

- **FCFS** — First-Come, First-Served allocation
- **Priority** — Allocation based primarily on agent value with a stochastic reliability component
- **Commitment** — Agents face stronger commitment incentives and dropout dynamics before allocation

The simulation varies:

- Number of agents (`N`)
- Available allocation slots (`K`)
- Fraction of strategic agents
- Estimated participation pool
- Agent valuations
- Stochastic dropout behavior

## Research Questions

The simulation investigates:

1. How does increasing strategic behavior affect allocation efficiency?
2. Which mechanism makes better use of scarce resources?
3. How do dropout and participation decisions affect realized allocations?
4. Which mechanisms remain robust across different supply-demand regimes?
5. What tradeoffs emerge between efficiency and fairness?

## Simulation Model

### Agent Valuations

Each agent receives a private valuation sampled independently from a uniform distribution:

$$
v_i \sim Uniform(0,1)
$$

### Strategic Behavior

Each agent is independently classified as strategic according to the specified strategic-agent fraction.

Strategic agents face different participation costs and dropout behavior depending on the mechanism.

### Participation Decisions

Agents compare their expected benefit from entering the allocation market against an entry cost:

$$
Expected\ Benefit = v_i \times P(Acceptance)
$$

An agent participates when:

$$
Expected\ Benefit > Entry\ Cost
$$

The estimated acceptance probability depends on the allocation mechanism and expected participant pool.

### Dropout Behavior

Dropout probability depends on agent valuation and strategic behavior:

$$
P(Dropout) = 1 - v_i
$$

Strategic agents receive an additional dropout component, while the commitment mechanism reduces the resulting dropout probability.

## Allocation Mechanisms

### 1. FCFS — First-Come, First-Served

Agents who enter are randomly ordered and offered allocations until capacity `K` is reached.

Realized allocations are then subject to stochastic dropout.

### 2. Priority

Participating agents are ranked using a combination of valuation and randomly generated reliability:

$$
Priority\ Score = 0.8v_i + 0.2r_i
$$

where:

- $v_i$ = agent valuation
- $r_i$ = stochastic reliability score

The highest-ranked agents receive offers, followed by stochastic dropout.

### 3. Commitment

Participating agents first pass through a mechanism-specific dropout stage. Agents who remain committed are randomly ordered and allocated available slots.

This creates a mechanism where commitment directly affects the probability of receiving a realized allocation.

## Evaluation Metrics

### Efficiency

Total valuation generated by the realized allocation:

$$
Efficiency = \sum_{i \in A} v_i
$$

where $A$ is the set of allocated agents.

Higher values indicate that the mechanism generated greater aggregate value.

### Seat Wastage

The fraction of available capacity that remains unused:

$$
Wastage = \frac{K - |A|}{K}
$$

Lower values indicate better resource utilization.

### Fairness

Average valuation among allocated agents:

$$
Fairness = \frac{1}{|A|}\sum_{i \in A}v_i
$$

This measures the average value of recipients and provides an additional perspective on allocation quality.

## Experimental Design

| Parameter | Values |
|---|---|
| Agents (`N`) | 150, 200, 250, 300 |
| Capacity (`K`) | 30, 60, 100, 140 |
| Strategic-agent fraction | 0% → 100% |
| Pool fractions | 25%, 50%, 75% |
| Repetitions per configuration | 300 |

The simulation evaluates each mechanism across a range of supply-demand conditions and strategic-agent compositions.

Across the experimental grid, the model performs **150,000+ stochastic simulation trials**.

## Statistical Analysis

For every mechanism and experimental configuration, the simulation computes:

- Mean efficiency
- Mean wastage
- Mean fairness
- Standard error for each metric
- Approximate 95% confidence intervals

Confidence intervals are visualized using:

$$
\mu \pm 1.96 \times SE
$$
